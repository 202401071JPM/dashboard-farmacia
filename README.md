# Dashboard de Ventas: Farmacia

Dashboard en Power BI que responde cuatro preguntas de negocio:
1. Participación de productos y categorías
2. Importe completado por mes y sede
3. Unidades por producto y categoría
4. Importe por segmento y categoría

Fuente: base de datos PostgreSQL (farmacia).
Limpieza de datos en Power Query y medidas DAX.
